# Vault Pass

Generador de contraseñas con **medidor de fortaleza**.

- Aleatoriedad con `crypto.getRandomValues`
- Longitud 8–48 y conjuntos configurables
- UI limpia, lista para demo en Pages

## Uso

Abre `index.html`.
